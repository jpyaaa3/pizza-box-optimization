# HeatPro 상자 생성기

## 실행 방법

Windows에서는 `HeatPro.cmd`, Linux 데스크톱에서는 `./HeatPro.sh`로 GUI를 연다.
Ubuntu 서버나 데스크톱에서 Python 3.10 이상으로 처음 설정할 때는 다음 명령을 실행한다.

```bash
./setup_venv.sh
./HeatPro.sh
```

설치 스크립트는 프로젝트의 `.venv`를 생성하거나 재사용하고 의존성을 설치한다.
Ubuntu 시스템 패키지가 빠져 있을 때만 관리자 권한을 사용한다.
화면 없는 서버에서는 설정 후 `./HeatPro.sh --cli --workers 8`로 GA를 실행한다.

## 정다각형 링과 한 장짜리 전개도

```powershell
python -B .\ring_box.py --count 5 --nonconvex --seed 42 --out-dir .\ring_candidates
```

인접한 정다각형 링의 연결 인덱스와 대각선 방향을 골라 평평한 삼각 패널을 만든다. 각 링의 반지름과 회전각, 간격도 달라질 수 있다. 평평한 바닥과 피자에 대한 1 mm 측면·상단 여유를 검사한다. 기본값은 바닥을 포함한 링 4–8개를 무작위로 뽑는다. `--sides`와 `--bands`로 변 수와 옆면 층 수를 고정할 수 있다. 예를 들어 `--bands 7`이면 링 8개다. `--nonconvex`는 실제로 오목한 공동만 남기는 옵션이다.

후보마다 전개도가 한 장으로 연결되고 면과 탭의 내부가 겹치지 않는지를 확인한다. 다층 형상은 바닥 각 변에 옆면 띠를 붙여 펼쳐 보고, 필요하면 다른 절단선과 접힘선 조합을 탐색한다. `--unfold-attempts`와 `--max-draws`로 탐색 횟수를 제한한다. 지정한 시도 안에서 전개도를 찾지 못한 형상은 건너뛴다. 기본 전개도에는 접착 탭이 없다.

SVG는 mm 단위 1:1 전개도다. 검은 실선은 절단선, 파란 점선은 접힘선이다. OBJ는 mm 단위의 두께 없는 공동 표면이다. 질량은 탭을 포함한 판재 면적에 3 mm 두께와 지정 밀도를 곱한 값이다. 실제 3 mm 판재를 조립할 때의 두께 간섭 및 닫힘은 별도 검증 대상이다.

Python 3.12에서 `numpy`와 `scipy`를 사용한다. HeatPro 폴더에서 다음 명령으로 무작위 후보 세 개를 만들고 mm 단위 OBJ를 저장한다.

```powershell
python .\box_generator.py --count 3 --obj-dir .\candidates
```

기본적으로 바닥 변 수(3–12)와 위쪽 점 수(1–16)를 후보 제안마다 독립적으로 뽑는다. 바닥 변의 방향과 거리, 위쪽 점의 x·y·z 좌표도 무작위로 뽑고, 피자를 수용하는 기하만 남긴다. 개수와 좌표 범위는 샘플링 설정이다. `--seed 42`를 추가하면 같은 후보를 재현할 수 있고, `--base-sides` 또는 `--upper-points`를 명시하면 해당 개수만 고정된다. 볼록 껍질 안에 묻힌 위쪽 점은 외형에 영향을 주지 않는다.

직접 좌표를 지정하려면 `BoxDesign`과 `build_box`를 사용한다. 아래는 내측 치수가 320 × 320 × 50 mm인 기준 상자다.

```python
from box_generator import BoxDesign, build_box

design = BoxDesign(
    base_angles_deg=(0, 90, 180, 270),
    base_distances_mm=(160, 160, 160, 160),
    upper_points_mm=((-160, -160, 50), (-160, 160, 50),
                     (160, -160, 50), (160, 160, 50)),
)
box = build_box(design)
print(box.mass_g, box.exposed_floor_area_m2, box.nonfloor_area_m2, box.air_volume_m3)
```

입력 좌표와 헐은 mm 단위이며, 안쪽 바닥은 `z=0`이다. OBJ에서는 외부 바닥이 `z=0`에 오도록 전체를 3 mm 올린다. 질량은 200 kg/m³ 판재를 적용한 이상 셸 값이며, 최종 제작 시 탭과 겹침을 추가해야 한다. 무작위 후보의 벽면 여유 기본값은 1 mm다. `build_box`는 기본적으로 기하학적 접촉까지 허용하며 `clearance_mm`으로 여유를 지정할 수 있다. CLI는 각 후보의 83–249 g 조건 충족 여부를 표시한다.

## 열 FEM 벤치마크

`fem_benchmark.py`는 Gmsh로 판재 체적과 피자 접촉면을 메시하고, `thermal_fem.py`에서 선형 사면체와 후진 오일러로 1,200초를 해석한다. 기준 상자와 후보별 메시·조립·분해·적분 시간, 최종 온도, 접촉 면적 오차 및 열수지 잔차를 출력한다.

```powershell
python -m pip install gmsh
python .\fem_benchmark.py --size-mm 4 --dt-s 1
python .\fem_benchmark.py --size-mm 6 --dt-s 2 --candidates 7
```

이미 `gmsh`를 불러올 수 있으면 설치 단계는 생략한다. `--size-mm`은 Gmsh의 최대 메시 크기 설정이다. 벤치마크 후보는 이상 셸 질량 범위를 통과한 무작위 후보 중 공기 부피가 다양한 형상을 뽑는다.

## 유전 알고리즘 실행

Windows에서 `HeatPro.cmd`를 더블클릭하거나 HeatPro 폴더에서 `python -B .\ga_ui.py`를 실행한다. 의존성은 `python -m pip install -r requirements.txt`로 설치한다. 기존 `.fem_runtime`이 있으면 GA는 그 안의 Gmsh를 우선 사용한다. UI의 **실행**으로 검색을 시작한다. 처음에는 개체 수 4, 세대당 새 후보 3, 세대 수 1로 입력하면 짧게 확인할 수 있다. 비워 둔 시드는 무작위로 선택되어 결과에 저장된다. **중지**는 진행 중인 후보를 마친 뒤 부분 결과를 저장한다.

**CPU 워커**는 동시에 평가할 후보 수다. 논리 CPU가 8개 이상인 PC에서 기본은 8개이고, 워커마다 Gmsh와 수치 라이브러리의 스레드를 1개로 제한한다. 컴퓨터를 같이 쓰려면 2~4개로 낮춰 실행할 수 있다.

**형상**의 기본값은 정다각형 링이다. 링 모드는 반지름, 높이, 비틀림, 대각선, 링 수 또는 변 수를 바꿔 자식을 만든다. 패널 연결이 같은 자식은 부모 전개도의 절단선과 접힘선을 먼저 시도한다. 한 장으로 이어지고 면이 겹치지 않는 전개도를 찾은 후보만 평가한다. `best_net.svg`에는 마지막 생존 1위의 1:1 전개도를 저장한다. 기존 생성 방식은 볼록 껍질을 선택해서 실행할 수 있다.

링 열모델은 각 평면 패널을 총 3 mm 두께의 사면체 요소 두 층으로 만들고, 접힘선의 노드에서 온도를 연속으로 잇는다. 접힘부와 탭의 실물 겹침은 열모델에서 생략한다. 링 GA 후보의 질량에는 접착 탭 없는 패널 면적을 사용한다. 비볼록 모양에 동일한 레이어 모델을 적용해 후보끼리 비교하며, 최종 제출 형상은 실물 솔리드 열해석이 필요하다.

후보별 8 mm·4초 열 FEM 결과를 수분 ODE에 넘긴다. 수분 ODE는 Tetens 포화압, 공기와 표면의 평균 필름 온도, 증발 및 응축만 허용하는 단방향 플럭스를 사용한다. 수분 잔류율의 메시별 순위 수렴은 별도로 검증해야 한다.

부모와 유효한 새 후보를 세대마다 합쳐 질량 오름차순, 최종 피자 온도 내림차순, 피자 수분 잔류율 오름차순의 등수를 구한다. 동점은 평균 등수를 사용하고, 세 항목 등수 합이 작은 후보를 유지한다. 볼록 껍질 모드의 질량 기준은 탭과 겹침을 포함하기 전의 이상 셸에 적용한다.

UI의 수분 함량은 남은 물 질량을 그 시점의 피자 질량으로 나눈 백분율이다. 피자의 초기 물은 300 g, 건조 고형분은 450 g이라 시작값은 40%다. CSV에는 수분 함량 `water_fraction_percent`와 과제 채점용 수분 잔류율 `water_percent`가 함께 저장된다. 두 값의 순서는 동일하다.

각 실행은 `ga_runs` 아래에 기록된다. `evaluations.csv`는 해석에 들어간 모든 후보와 실패 사유, `population.csv`는 마지막 생존 개체와 항목별 등수, `pareto.csv`는 누적 비지배 후보를 담는다. `best.obj`는 마지막 세대의 등수 합이 가장 낮은 후보의 셸이다.

터미널에서도 같은 계산을 실행할 수 있다.

```powershell
python -B .\ga.py --shape ring --population 4 --children 3 --generations 1 --workers 4 --seed 42 --out .\ga_runs\quick_check
```
